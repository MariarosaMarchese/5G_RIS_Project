# 5G_RIS_Project

This repository contains the configuration files and analysis scripts used to evaluate throughput and jitter performance in a 5G Standalone (SA) testbed based on OpenAirInterface (OAI).

The broader objective of the project is to investigate whether a **passive Reconfigurable Intelligent Surface (RIS)** can introduce statistically measurable improvements in standardized 5G radio-level performance indicators within a realistic indoor sub-6 GHz deployment.

The current version of the repository focuses on the **baseline analysis** of uplink and downlink performance under controlled indoor conditions at different UE–gNB distances. These baseline measurements are necessary to characterize the system behavior before introducing RIS-assisted scenarios.

The repository includes:
- the **gNB configuration** used in the experiment,
- the **Python scripts** used to process measurement logs and generate plots,
- the **processed datasets and figures** obtained from the experiments.


## Experimental Setup
The experiments were performed using the following configuration:
- **5G platform:** OpenAirInterface (OAI)  
- **Architecture:** 5G Standalone (SA)  
- **Radio hardware:** USRP B210  
- **Operating system:** Ubuntu  
- **Carrier frequency:** 4.18575 GHz (NR band n77)  
- **Subcarrier spacing:** 30 kHz  
- **Number of PRBs:** 51  
- **Occupied bandwidth:** ~18.36 MHz  
- **MIMO configuration:** SISO (1×1)

The system uses a **downlink-dominant TDD configuration**, meaning that most OFDM symbols are allocated to downlink transmission.

Traffic was generated using **iperf**, with a target downlink rate of **10 Mbps**.

Two UE–gNB distances were considered:
- **1 meter** (baseline condition),
- **2 meters**.

For each scenario, **three independent experiments** were conducted in order to evaluate repeatability and statistical consistency.

## Repository Structure

- **analysis/**: contains Python scripts used for data processing and plotting.
  - **figures/**: generated plots.
  - **outputs/**: processed results in CSV format.

- **data/**: contains the experimental datasets collected during the measurements.

- **gnb_config/**: contains the gNB configuration file used in the experiments.

## Running the Analysis

The plots can be generated by running:
```bash
python run_analysis.py
```

This script loads the measurement logs, computes statistical metrics,
and generates the throughput and jitter time-series plots.
